# شادستان 🎈

سایت سرگرمی با بازی، بانک، خلاف‌ورزی، لیدربورد و دوستان — با Supabase به‌عنوان بک‌اند.

## راه‌اندازی دیتابیس (یک بار)

1. برو به داشبورد پروژه‌ت روی supabase.com
2. از منوی سمت چپ برو به **SQL Editor**
3. یه **New query** بساز، محتوای فایل `schema.sql` رو کامل کپی/پیست کن و **Run** بزن
4. همین! جدول‌های `profiles` و `friends` با تنظیمات امنیتی (RLS) ساخته می‌شن

## آپلود روی گیت‌هاب

1. یه ریپوی جدید بساز (مثلاً `shadestan`)
2. همه‌ی فایل‌های این پوشه (`index.html`, `css/`, `js/`, و غیره) رو توش آپلود کن
3. برو به تنظیمات ریپو > **Pages** > سورس رو روی شاخه‌ی `main` بذار
4. بعد چند دقیقه سایت روی آدرسی شبیه `https://username.github.io/shadestan` بالا میاد

## نکته مهم درباره امنیت (صادقانه بگم)

توی این نسخه، امتیازها و سکه‌ها مستقیم از توی مرورگر کاربر به دیتابیس نوشته می‌شن (بدون یه سرور واسط که حساب کنه "این امتیاز واقعیه یا نه"). یعنی یه کاربر واردشده به‌حساب و کمی حرفه‌ای می‌تونه از طریق کنسول مرورگر خودش، مستقیم به‌جای بازی‌کردن، عدد سکه‌شو دستکاری کنه.

برای یه دموی شخصی یا بین دوستان مشکلی نداره، ولی اگه بعداً خواستی سایت رو عمومی و ضدتقلب کنی، باید منطق دادن جایزه رو ببری تو یه **Supabase Edge Function** (کد سمت سرور) به‌جای این‌که مستقیم از جاوااسکریپت صفحه بنویسی. اگه خواستی، بعداً همین کارو هم برات انجام می‌دم.

## چی‌ها رو می‌تونی بعداً عوض کنی

- سوالای کوییز: تو `js/games.js` آرایه‌ی `QUIZ_QUESTIONS`
- درصد سود بانکی (الان ۵٪): تو `js/bank.js`
- تعداد کلیک لازم برای فرار و مدت زندان: تو `js/games.js` تابع `startHeistGame`
- رنگ‌ها و فونت: تو `css/style.css` بخش `:root`
