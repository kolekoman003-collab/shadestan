# KoleGame 🎮🪙

نسخه ارتقایافته سایت بازی و سرگرمی با نام **KoleGame** و ارز مجازی **KoleCoin**.

## اول از همه: باگ صفحه بازی‌ها

باگ اصلی نسخه قبلی این بود که `.modal-overlay` با CSS همیشه `display:flex` داشت و حتی وقتی `hidden` بود روی صفحه می‌ماند؛ در نتیجه یک لایه روی کل سایت می‌افتاد و اجازه کلیک نمی‌داد. این نسخه با `.modal-overlay[hidden]{display:none!important}` آن مشکل را رفع کرده.

## اتصال به دیتابیس

ساختار قبلی حذف یا rename نمی‌شود. فایل `schema_upgrade.sql` فقط ستون‌ها، جدول‌ها و RPCهای جدید را به صورت additive اضافه می‌کند.

### نصب ارتقا
1. وارد Supabase پروژه فعلی شو.
2. SQL Editor > New query.
3. کل `schema_upgrade.sql` را اجرا کن.
4. اگر می‌خواهی قرعه‌کشی واقعاً بدون نیاز به باز شدن سایت، دقیقاً هر ۶ ساعت خودکار اجرا شود و پروژه‌ات pg_cron دارد، فایل `lottery_cron.sql` را هم اجرا کن. اگر pg_cron در پروژه فعال نباشد، اپ در اولین بازدید بعد از پایان بازه قبلی قرعه‌کشی را finalize می‌کند.
5. فایل‌های این پوشه را جایگزین فایل‌های قبلی روی GitHub کن.

- نام و برند: **KoleGame**
- ارز مجازی: **KoleCoin**
- لول و XP
- استریک ورود روزانه
- جایزه روزانه سرور-محور
- انتقال اتمیک KoleCoin بین کاربران با نام کاربری
- بانک با واریز/برداشت اتمیک و سود روزانه
- گردونه شانس رایگان هر ۶ ساعت
- لاتاری هر ۶ ساعت با بلیت‌های قابل خرید؛ تعداد بلیت بیشتر، شانس بیشتر
- کازینو مجازی با KoleCoin: شیر/خط، تاس و اسلات
- ۱۶+ حالت بازی شامل واکنش، حافظه، کوییز، فرار از پلیس، ستاره‌گیری، موش بزن، سنگ‌کاغذقیچی، حدس عدد، دوز، گردونه، لاتاری، کازینو، تیراندازی هدف، عدد گمشده و فرار موشکی
- بیش از ۱۰۰ سؤال کوییز؛ هر بار ۱۰ سؤال تصادفی انتخاب می‌شود تا پشت‌سرهم تکراری نباشد
- المان‌های متحرک، نوارهای بی‌نهایت، کارت‌های hover و رابط واکنش‌گرا
- عملیات اقتصادی مهم با RPC سمت دیتابیس برای کاهش race condition و تقلب ساده
